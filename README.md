# rubicon-secret-santa

A planned privacy-first Secret Santa web app for Cloudflare Workers. The goal: the draw happens
on the server and each person is emailed only their own match, so the organizer can take part
without seeing anyone else's assignment, and game data is deleted automatically after a set period.

The source is open so anyone can read exactly what happens to their data, and run their own copy.
No ads, no affiliate links, no upsell.

> The project name is provisional.

## Status

Pre-alpha. The design is being written; there is no working app yet.
